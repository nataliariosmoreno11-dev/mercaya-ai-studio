# Recursos visuales locales

- `mission-commerce.svg`, `growth-commerce.svg`, `action-automation.svg`: composiciones SVG originales creadas para este proyecto. Transparencia, degradados y sombras para sugerir volumen; no se presentan como renders 3D. Sin recursos remotos, marcas de agua ni logotipos de terceros.
- `mercaya-commerce-3d.png`: recurso generado con IA en una iteración anterior, conservado como archivo histórico. La interfaz actual utiliza los SVG.

El smartphone, productos, precios y botón Comprar son decoración ficticia sin interacción y no forman parte de los datos, métricas ni resultados del assessment.
